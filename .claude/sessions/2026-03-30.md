# Session: 2026-03-30 — Speed optimization

## What changed
- Rewrote file opening to use named pipe + Go launcher (1ms vs 600ms Electron second-instance)
- Added system tray mode — app stays resident, windows open/close freely
- Implemented ready-pool: pre-warmed hidden BrowserWindow for instant second-file opens
- Fixed warm window to use `mt::open-new-tab` (not custom swap that left blank screens)
- Simplified close handler — windows just close, app stays alive via tray
- Added automated benchmark suite with screenshot verification

## Key decisions
- Named pipe (`\\.\pipe\marktext-viewer`) over Electron's single-instance IPC — eliminates 600ms process launch
- Go launcher over batch/PowerShell — 1ms startup, 2.3MB binary
- Ready-pool over hide-to-tray reuse — simpler, no race conditions, each file gets clean window
- `mt::open-new-tab` over custom `viewer-swap-content` — warm window needs a real tab, not content swap into nonexistent editor
